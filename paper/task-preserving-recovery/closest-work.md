# Closest work and novelty boundary

**Scope:** primary arXiv method text and relevant supplement read on September 10, 2026; no external method was reproduced. Versions below identify the actual inspected artifacts. A downloaded full paper does not imply that every proof, implementation or reported measurement was independently validated. Local HTML/text snapshots and SHA256s are retained privately in `outputs/methods_development_20260910/sources/manifest.json`. This is a targeted comparison of the ten requested works, not a systematic novelty guarantee.

## What is distinct, and what is not

**Not a novelty claim:** global position feedback; a fixed evaluation reference by itself (CLOT already retains the reward reference); action anchoring; freezing a backbone; residual/adaptor learning; generic post-training; uncertain observations; recovery; constrained optimization. Combining familiar nouns does not create algorithmic novelty.

**Defensible research question:** can explicit rollout-level retention budgets improve the recovery–retention tradeoff when adapting a capable tracker to a fixed, time-indexed task under characterized localization and dynamics uncertainty? The inspected methods do not establish the same joint experimental contract. That observation supports studying it; it does not prove nobody has studied it elsewhere.

**Candidate contribution, conditional on results:** a task-preserving post-training procedure with origin-relative rollout costs, physically specified recovery events and a matched-information evaluation showing better budget attainment or a better frontier than tuned feedback, regularization and adapter baselines. This is currently a hypothesis about an empirical method/system contribution. The primal–dual machinery itself is standard, and there is no present theorem or novel optimizer.

The novelty case is weakest if a simple Lagrangian added to an existing adapter is the entire contribution and only an information-disadvantaged baseline loses. It becomes more defensible if the study identifies when cached action anchoring fails to control trajectory-level degradation, demonstrates that the proposed update addresses that failure across independent origins, and quantifies which uncertainty regimes remain outside the method’s usefulness. Negative outcomes must change the paper’s conclusion.

## Mandatory comparator priority

1. Common-feedback ordinary fine-tuning and an equally tuned constant-anchor sweep establish whether a new constrained update is needed.
2. The current two-column input repair or a bounded action residual tests whether representation complexity is needed.
3. A supported saturated path outer loop tests whether learned correction is needed at all.
4. Any2Track-style history-informed adaptation and CLOT-style observation pre-shift are the closest method competitors. Use released implementations where compatible; document every deviation when adapting them.
5. PPF-style reliability regularization, ResMimic-style residual refinement and termination-window controls test specific alternative explanations. StableMimic/Stubborn native recovery numbers are not directly interchangeable with fixed-path recovery.
6. Actuator calibration and ASAP-like alignment are system alternatives if transfer fails, not obligatory extra models in the first pilot.

The simplest alternative can invalidate a component’s necessity without invalidating the value of the task or benchmark. If a tuned fixed anchor matches the constrained learner within a prespecified meaningful margin with adequate precision, use the simpler procedure and withdraw the stronger optimizer claim.
