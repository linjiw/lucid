# Anonymous diagnostic data dictionary

This package contains compact recorded simulation inputs, not checkpoints, motion datasets or private raw logs. It regenerates displayed analyses without a simulator. Physical replication additionally requires the declared SONIC version, robot/motion assets and training/evaluation configurations; this package does not claim a fresh simulator reproduction.

`data/manifest.json` hashes every input file. Each `source_<SHA256>` identifies a private source by content hash and byte count. Absolute paths and online account identifiers are excluded. The private source map is deliberately outside this package. Each continuation metric file is checked against the hash in its frozen receipt before export.

| File | Fields and interpretation |
|---|---|
| retention_episodes.json.gz | 135 panels / 69,120 episode records. Key: continuation_seed, arm, iteration, condition. Two origin panels are retained separately by campaign. Each has 512 unique motion_index values identifying repeated copies of M1. evaluation_seed is a process seed, not evidence of matched perturbation streams. checkpoint_sha256 binds the evaluated policy. |
| Episode record | completed: boolean completion; valid_samples: pre-step first-episode samples; global_mpjpe_mm/local_mpjpe_mm: episode means over valid samples, including failed episodes. tracking_qualified is the original 600/50 mm boolean, recomputed by the analyzer. Global positions are world-frame; local positions subtract each pose's root without heading alignment. No per-step trajectories or draw-stream identifiers are inferred. |
| historical.json | All twelve mode/seed policies; checkpoint_iteration=8000, from-scratch origin; terminal_return is the last-500-iteration mean from the scalar receipt. Each stored ladder cell provides completion/progress, evaluation seed and checkpoint hash. Some original receipts contain only the four frontier rungs; absent in-envelope cells are not imputed. Arm-specific controller states establish actual strata/gains. |
| range_traces.json.gz | Original recorded global_step and lambda for each of the twelve policies. B's lambda is maximum cohort intensity; cohort scales are 1/4, 1/2, 3/4, 1 times lambda. No smoothing is applied. |
| tolerance.json | Frozen full-precision per-seed AUC inputs and empirical decision settings for never-shrink versus fixed. Frontier rungs 1.25,1.5,1.75,2 carry weights 1,2,2,1 divided by 6. In-envelope rungs 0,.25,.5,.75,1 carry weights 1,2,2,2,1 divided by 8. |
| method.json | Recorded common reward/PPO/physical configuration, executed continuation optimizer start, encoder architecture/training metadata and anonymous anchor-buffer summary. Common config labels do not override arm-specific controller state. Cached targets/observations and policy parameters are not distributed. |
| anchor_validation.json | Existing native CUDA/TF32 target replay and pre-update identity validation. CPU and direct 256-row precision diagnostics are explicitly unsuccessful. |
| secondary_controls.json | Legacy pilot and optimizer-history controls, separate 128-copy nominal panel, and measured continuation costs. Legacy MPJPE is a different accumulator from the primary first-episode means; denominators must not be pooled. |
| mujoco.json | Individual completion booleans for five historical policies × three scales × two push settings ×32 draws. These draws and simulator conditions are separate from Isaac continuation measurements. |
| signal_audit.json / channel_sweep.json / secondary_motion.json | Existing secondary scalar receipts, with identifying paths removed; supplied for provenance of the bounded secondary discussion, not additional independent main-paper comparisons. |

`analysis/retention_constituents.csv` exposes every protected-condition error and completion measurement alongside its matching origin. `analysis/retention_summary.csv` contains D, L and pass status. D is the maximum relative global/local error increase over nominal and original-envelope conditions; L is maximum completion loss in percentage points. Improvements can make these values negative. A point passes iff D≤10 and L≤2. Missing or invalid measurements fail analysis rather than passing the gate.

`analysis/all_condition_scalars.csv` includes all five evaluation conditions. Hard Q equally weights ch_push_350 and ch_push_fric_350_150. Primary Q requires completion and global/local means ≤600/50 mm. `analysis/threshold_sensitivity.csv` covers every saved checkpoint at the fixed reporting grid {400,500,600,700,800} × {40,45,50,55,60} mm. This is retrospective development analysis; every combination is retained. A best feasible checkpoint selected from these panels is exploratory, not held-out deployment performance.

Historical differences are paired by training seed, not by episode. Continuation seeds 8600/8601 reuse the same trained origin, cohort assignment and anchor-sampling seed. The package does not establish perturbation-stream pairing or independent-origin replication.
